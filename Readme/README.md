# Flores Amarillas con Estrellas y Meteoritos 🌼✨

Este proyecto combina un cielo animado con estrellas y meteoritos junto con flores amarillas animadas, ideal para compartir como un detalle especial.  

## 🚀 Vista previa
Al activar **GitHub Pages**, podrás abrir este proyecto como una página web pública.
